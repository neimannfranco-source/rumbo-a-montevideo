# Rumbo a Montevideo

Guía interactiva de español para viajar a la final de la CONMEBOL Libertadores 2026 (Palmeiras – Estudiantes, Estadio Centenario, Montevideo, 28 de noviembre).

Pensada para estudiantes brasileños: todas las frases tienen traducción al portugués.

## Qué incluye

- 9 paradas en el orden del viaje (lo básico, aeropuerto, hotel, transporte, comida, compras, día del partido, imprevistos y español uruguayo)
- En cada parada: frases para decir, frases que van a escuchar, vocabulario, simulación de diálogo y desafío
- Pasaporte de sellos que se completa al superar los desafíos
- Duelo por turnos entre dos jugadores
- Voseo, falsos amigos, números y precios, mapa de Montevideo, plan del día de la final, ficha para mostrar y lista de equipaje
- Audio con la voz en español del dispositivo (prioriza Uruguay y Argentina)
- Guía de bolsillo en PDF para usar sin internet: `guia-de-bolsillo-montevideo.pdf`

## Cómo usarla

Abrir `index.html` en el navegador. No necesita instalación. El progreso se guarda en el navegador de cada alumno.

Para publicarla con GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.
